VIBECUBATOR
AI-assisted Project Development & Production Framework

VIBECUBATOR is an open-source framework for planning, developing, documenting and managing projects with the assistance of different AI systems.

Its primary goal is to make long-term AI-assisted development reliable, consistent and reproducible.

The problem

Large projects often suffer from:

Loss of context between AI sessions.
Contradictory recommendations from different AI systems.
Repeated work and forgotten decisions.
Incomplete documentation.
Unclear development status.
Difficulties resuming work after longer breaks.

VIBECUBATOR addresses these problems through a persistent project memory, structured planning and a mandatory AI Session Handover process.

Core principles
AI independence: No dependency on a single AI provider.
Cost flexibility: Browser-based, local and API-based AI.
Persistent project memory: Project knowledge exists independently of chat histories.
Structured planning: Clear phases, milestones and tasks.
Traceability: Decisions, changes and test results are documented.
Human control: Important project decisions require human approval.
Mandatory handover: Every development session must leave a usable record.
AI operating modes
Browser AI – manual task and result exchange with accessible browser-based AI services.
Local AI – locally operated models, initially with Ollama.
API AI – integration with external AI providers through official APIs.

Development philosophy

VIBECUBATOR will initially be developed as a local application.

The project will be built in clearly defined phases. Documentation, testing and session handover are integral parts of development.

No major implementation begins without an agreed plan and documented requirements.
